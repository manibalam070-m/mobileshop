# MobileHub — React JS Online Mobile Sales Project

A modern responsive frontend for an online smartphone store.

## Features
- Responsive React + Vite UI
- Search smartphones
- Filter by brand
- Sort by price/rating
- Product cards with offers and ratings
- Wishlist/favorites
- Add to cart
- Quantity controls and remove items
- Cart subtotal, delivery and total calculation
- Checkout form
- Payment method selection
- Newsletter form
- Mobile responsive navigation
- Modern e-commerce design

## Requirements
- Node.js 18+ recommended
- npm

## Run the project

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite, usually:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
npm run preview
```

## Important
This is a frontend/demo project. Products use sample data and remote demo images. A real production store should connect the cart, authentication, inventory, orders, payments and product database to a backend/API.
